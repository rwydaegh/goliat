# PMB paper

This directory contains the final submitted manuscript associated with GOLIAT.

- `paper.pdf`: clean final manuscript
- `supplementary_information.pdf`: final supplementary material
- `source/`: LaTeX source, journal class, and referenced figure assets

The supporting simulation configurations and postprocessed data are available
through Harvard Dataverse. The public record URL is a release-day launch gate.

Build the manuscript from `source/` with the journal's standard LaTeX workflow.
Generated LaTeX intermediates are ignored.
